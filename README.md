# UseBlocky Design Practical: Fix the Swap Screen

**Time limit: 20 minutes** (hard stop at 30). Please don't spend longer. We would rather see good judgment in a short time than polish.

## The situation

This is a simplified token-swap screen from a multi-chain dApp. Users are confused by it and often abandon it. Your job is to make it clearer and easier to use.

## What you need

- VS Code
- Git
- A browser (open `index.html` directly)

No frameworks or build tools. Plain HTML and CSS only. A little JavaScript is fine if you need it to show a state.

## Steps

1. **Clone** this repo and open the folder in VS Code.
2. **Create a branch** named `redesign/<your-name>`.
3. **Review the screen** in your browser and decide what hurts users most.
4. **Improve it.** Required:
   - Fix the **3 biggest usability problems** you find.
   - Make the **failed-transaction state** clear and helpful (what happened, what to do next).
   - Make it usable at **375px wide** (mobile).
5. **Commit as you go.** At least 2 commits with clear messages (e.g. `Improve button contrast and size`).
6. **Add a short note** in a file called `NOTES.md` (3 to 5 sentences):
   - The 3 problems you fixed and why
   - One thing you would do next with more time
7. **Submit**: push your branch and send us the link. If you cannot push, run `git format-patch main` and email us the generated `.patch` files.

## Ground rules

- Incomplete is fine. Tell us what you skipped in `NOTES.md`.
- If you use AI tools or copied snippets, tell us in `NOTES.md`. It will not count against you.

Good luck!
